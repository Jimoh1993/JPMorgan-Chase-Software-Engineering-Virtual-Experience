# JPMorgan Software Engineering Projects

## Overview

This repository contains software engineering projects completed through the **JPMorgan Chase Software Engineering Virtual Experience Program** hosted by **Forage**. The projects demonstrate practical software engineering concepts applied to financial technology scenarios, including data processing, software development, and visualization of market information.

The work involved designing and implementing **Python-based solutions** to simulated engineering tasks inspired by real-world financial systems, including data analysis, software development, and web-based visualization.
